# Посмотри в окно

Проектная работа третьего спринта курса «Фронтенд-разработчик» Яндекс Практикума.

«Посмотри в окно» — одностраничное приложение, в котором можно смотреть видео из окон в разных городах. Скрипт загружает ролики с сервера, выводит карточки с превью, подставляет выбранное видео в основной блок и ищет ролики по городу и времени суток.

В проекте свёрстан внешний вид уже работающего приложения по макету в Figma:

- лейаут страницы на флексбоксе;
- блок с видео, подогнанным через `object-fit`;
- форма поиска с текстовым полем и кастомными чекбоксами на псевдоэлементах;
- кнопки «Найти» и «Показать ещё» с состояниями `:hover`, `:active` и `:focus-visible`;
- список карточек со скроллом, обрезкой длинного заголовка многоточием и ограничением описания по числу строк (`line-clamp`);
- состояния карточек: текущая, активная, при наведении и в фокусе;
- позиционирование прелоадеров и блока ошибки внутри своих контейнеров.

## Технологии

- HTML5 (теги `<template>` для разметки, которую создаёт скрипт)
- CSS3: Flexbox, псевдоклассы `:has()`, `:checked`, `:focus-visible`, псевдоэлементы, `object-fit`, `line-clamp`
- JavaScript (логика приложения дана в заготовке)

## Как открыть

Склонируйте репозиторий и откройте `index.html` в браузере. Для загрузки видео нужен доступ в интернет. Страница рассчитана на ширину экрана от 1200px.

```bash
git clone https://github.com/liewwsLu/posmotri-v-okno-ad.git
```
